LAYOUT:

Authors:
> Array of lists inside a list
    > IDs: First Name, Last Name, Age, Field of Study
    > Example: Rick, Riordian, 62, Fictional Literature
Papers:
> Array of lists inside a list
    >IDs: Title, Author (Not List Specific), Field of Study, Post Date, Link (Optional)
    >Example: Eyelid Myokymia, Abd Alkader Jafer Chardoub & Bhupendra C. Patel, Health Science, 08/08/2023, https://www.ncbi.nlm.nih.gov/books/NBK560595/

Creation:
> Create a Paper
> Create an Author

Read:
> Load all Papers into a List with Info
> Load all Authors into a List with Info

Update:
> Offer a list of papers to choose from. Have the user pick a number from the list.
    > Call the numbered paper, open a menu similar to the "Create a Paper" menu that allows the user to edit all of the information for a paper. Update the info for the Paper upon pressing the submit button
> Use the same system as above for Authors.

Delete:
> Use the same number list as "Update", allowing the user to choose a Paper or Author. Use the chosen number to select an Author or Paper, and delete it from the list of stored Authors and Papers
